# Atendimentos

Catálogo de atendimentos reais do suporte do Cherp ERP, usado como base de pesquisa. Cada atendimento tem um assunto, o objetivo e o procedimento que resolveu o caso.

---

## Atendimento: Numeração sequencial dos contratos

Assunto: numeração de contratos, número inicial do contrato, sequência numérica, próximo número do contrato.

Objetivo: orientar os clientes a configurar a numeração dos contratos e entender como funciona a sequência numérica no Cherp ERP.

Passo a passo:
1. Acesse o menu Configurações.
2. Entre na aba Empresa.
3. Na parte inferior da página, localize o campo "Número inicial do contrato".
4. Verifique o número configurado e oriente o cliente sobre o ajuste necessário para continuar a sequência usada pela empresa.

Exemplo prático: se o último contrato usado foi o número 501082, o próximo número esperado é 501083. Conforme a orientação do suporte, o cliente pode ajustar o campo de numeração para o último número usado, de modo que o próximo contrato receba o número seguinte. O mesmo raciocínio vale para uma sequência como 205082 → 205083.

Atenção:
- A configuração vale somente para o número do contrato, não para a referência do contrato.
- A documentação consultada não confirma a existência de um botão para verificar o próximo número disponível.
- Se o cliente usa duas sequências independentes, verifique como elas estão organizadas antes de orientar uma alteração. O manual não confirma que o sistema controle duas sequências separadas por meio dessa configuração.

## Atendimento: Cadastro de benefícios para clientes

Assunto: benefícios, cadastrar benefício, vincular benefício ao plano, benefícios do titular e dos dependentes, telemedicina, assistência funeral.

Objetivo: orientar o cliente a localizar os benefícios e vinculá-los aos planos.

A. Cadastrar um novo benefício
1. Acesse o menu Planos.
2. Entre na seção Benefícios.
3. Cadastre o benefício que será usado nos planos.

Os benefícios são serviços que podem ser reaproveitados em diferentes planos, como telemedicina, assistência funeral e outros serviços disponíveis.

B. Vincular benefícios a um modelo de plano
1. Acesse Planos → Modelos de Planos.
2. Localize o modelo desejado e abra a edição.
3. Acesse a seção correspondente aos benefícios.
4. Configure os benefícios do titular e, quando aplicável, dos dependentes.
5. Confira as demais configurações do modelo antes de concluir.

O modelo define os benefícios incluídos no plano contratado pelo cliente.

C. Gerenciar benefícios em um plano já contratado
1. Acesse o menu Planos.
2. Localize o plano do cliente.
3. Clique na linha correspondente para abrir os detalhes.
4. Selecione "Configurar plano".
5. Use as opções disponíveis para gerenciar os benefícios e os dependentes do titular.

## Atendimento: Registrar óbito de dependente

Assunto: óbito, falecimento, dependente falecido, registrar morte, data do velório, data do sepultamento, situação óbito.

Objetivo: orientar a equipe de suporte sobre como registrar o óbito de um dependente no sistema Cherp.

Passo a passo:
1. Acesse a área em que os dependentes estão cadastrados.
2. Clique no dependente desejado para acessar as informações dele.
3. Clique em "Editar".
4. Registre o óbito e preencha as datas solicitadas:
   - Data do falecimento;
   - Data do velório;
   - Data do sepultamento.
5. Salve as alterações.
6. Verifique se a coluna "Situação" foi atualizada automaticamente para "Óbito".

Resultado esperado: as informações do falecimento ficam registradas no cadastro do dependente, e a situação dele é atualizada automaticamente pelo sistema.

## Atendimento: Alteração automática da categoria do plano

Assunto: nome do plano muda sozinho, categoria do plano, prefixo do plano, benefícios adicionais, benefício extra, Plus, Pro, Master, regras do modelo de plano.

Objetivo: orientar a equipe de suporte sobre como configurar a alteração automática do nome de um plano conforme a contratação de benefícios adicionais.

Passo a passo:
1. Acesse o menu Planos, onde são exibidos os modelos de planos ativos.
2. Localize o modelo de plano desejado e clique em "Editar".
3. Acesse a subaba "Regras".
4. Localize a configuração que permite definir o prefixo ou nome usado na alteração automática do plano quando forem adicionados benefícios extras.
5. Configure as nomenclaturas conforme a regra desejada e salve as alterações, caso solicitado.

Exemplo prático: um plano da categoria Bronze tem dois benefícios incluídos. Ao adicionar um terceiro benefício, o sistema pode atualizar automaticamente o nome do plano conforme a nomenclatura definida nas regras, como Plus, Pro ou Master.

Resultado esperado: o sistema atualiza automaticamente a nomenclatura do plano conforme a contratação de benefícios adicionais, de acordo com as regras configuradas.

Atenção para o suporte: confirme com o cliente quais nomenclaturas e critérios ele deseja usar antes de orientar a configuração. Os nomes e a quantidade de benefícios do exemplo são ilustrativos; a regra exata depende da configuração feita no sistema.

## Atendimento: Consulta de eventos do cliente

Assunto: eventos do cliente, aba Eventos, onde ver os eventos, eventos da planilha, histórico de eventos no cadastro do cliente.

Objetivo: orientar a equipe de suporte sobre como localizar os eventos cadastrados para um cliente no Cherp ERP.

Passo a passo:
1. Acesse o menu Clientes.
2. Localize e abra o cadastro do cliente desejado.
3. Dentro da página do cliente, acesse a aba "Eventos".
4. Consulte os eventos cadastrados para aquele cliente.

Funcionamento: todos os eventos cadastrados pelo usuário na planilha são exibidos na subaba "Eventos", dentro da página do respectivo cliente.

Resultado esperado: o usuário consegue consultar os eventos vinculados ao cliente diretamente no cadastro dele, sem precisar procurar essas informações separadamente na planilha.
